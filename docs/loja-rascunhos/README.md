# Pré-visualizações da ficha

As duas imagens foram capturadas num telemóvel, usando a página visual isolada e dados fictícios. São rascunhos, não capturas finais: mostram a barra do navegador e não reproduzem exatamente a aplicação instalada. Não publicar como imagens da Play Store.

Para a versão final, captar a aplicação Android real com uma conta de teste e dados fictícios, sem expor dados financeiros, emails, notificações ou informação pessoal. Rever as imagens, as dimensões e os requisitos atuais da loja antes de as enviar.
